# 俄罗斯方块（浏览器版）

## 怎么启动游戏

### 方式一：一键启动（推荐）

在项目目录执行：

```bash
./start.sh
```

启动后浏览器打开：

- `http://localhost:4173`

也可以自定义端口，例如：

```bash
./start.sh 8080
```

然后访问 `http://localhost:8080`。

### 方式二：直接用 Python 启动

```bash
python -m http.server 4173
```

然后访问：`http://localhost:4173`

## 操作说明

- `←` / `→`：左右移动
- `↑`：旋转
- `↓`：加速下落（软降）
- `Space`：直接下落（硬降）
- `P`：暂停 / 继续

也可以点击页面按钮：

- **开始 / 重新开始**
- **暂停 / 继续**
